## Дроп с этого профиля

### Игры (Unity C#)

| Предмет | Что делает, если подобрать |
| :--- | :--- |
| **[DungeonSeeker](https://github.com/MASh4p/DungeonSeeker)** | Данж, хаб, инвентарь и союзник с ИИ. Behavior + Utility AI + ML-Agents. босс этой катки. |
| **[Vampiric-game](https://github.com/MASh4p/Vampiric-game)** | Survivors-like на ECS. волны, эволюции оружия, карты. «ещё один забег и спать» — враньё. |
| **[Clicker](https://github.com/MASh4p/Clicker)** | Кликер для Яндекс Игр. жмёшь по врагу, как по этой странице. WebGL в репо. |
| **[Tower Invasion](https://github.com/MASh4p/Tower-Invasion)** | 2D action: удар, блок, перекат. командный рейд на 10 человек. |

### Приложения (C# ASP.NET, Python, JS)

| Предмет | Эффект |
| :--- | :--- |
| **[ItchDB](https://github.com/MASh4p/ItchDB)** | Локальное веб-приложение на C# и .NET 10, которое собирает публичные страницы itch.io и считает по ним медианы, шансы, конкуренцию и тренды. [Превью](https://mash4p.github.io/ItchDB/) |
| **[YandexGamesDB](https://github.com/MASh4p/YandexGamesDB)** | .NET, анализирует каталог Яндекс Игр и считает спрос по жанрам, тегам, GQ, отзывы, инапы, платформы, описание, медианы, индекс перспективы. |
| **[PostupiCalc](https://github.com/MASh4p/PostupiCalc)** | Считает зачисление в вуз по CSV с Госуслуг. [Использовать](https://MASh4p.github.io/PostupiCalc/) |
| **[OneClickSend](https://github.com/MASh4p/OneClickSend)** | Android-ульт: одно нажатие — фото улетает в Telegram или ВК. |
| **[personal-vpn](https://github.com/MASh4p/personal-vpn)** | Бафф невидимости для выбранных приложений. свой WireGuard, не чужой «бесплатный VPN». |
| **[ImageCollectHelper](https://github.com/MASh4p/ImageCollectHelper)** | Автоматический сбор изображений с открытой лицензией по заданным параметрам. |

### Учебные проекты (Python, Jupyter)

| Предмет | Задача |
| :--- | :--- |
